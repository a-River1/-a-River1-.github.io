[059] 2026-09-19T18:28:34.333Z | ASSISTANT
- **OpenAI:** Turns the user’s question and context into search queries, searches the web for additional sources, and summarizes retrieved evidence. Requests use the Responses API with a model name, instructions, input text, and a JSON schema for structured results.
- **CourtListener:** Searches court opinions using legal keywords, then retrieves opinion text when available. Results supply case names, courts, dates, citations, and passages used for annotations.
- **GovInfo:** Searches federal collections—including the U.S. Code, federal regulations, public laws, and court opinions—using a query and result limit. It returns JSON metadata and document links; the app also retrieves document text when available.
- **Open States:** Searches bills using legal keywords and the selected state. It returns JSON containing bill titles, identifiers, abstracts, and legislative actions, which the app displays as legislative history rather than automatically treating them as current law.
